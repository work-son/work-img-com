# work-img v2

日本ユーザー向けの画像圧縮Webサービス用デプロイパッケージです。
画像ファイルは外部サーバーへ送信せず、ブラウザ内で処理します。

## 主な機能
- JPG / PNG / WebP / ブラウザ対応時AVIF入力
- 圧縮品質のリアルタイム表示・再圧縮
- 出力形式の変更
- 画像サイズ縮小
- 一般的なEXIF等のメタデータ除去
- 複数画像の一括ダウンロード
- モバイル対応
- 日本語 / 韓国語 / 英語切り替え
- SEO基本設定
- プライバシーポリシー / 利用規約 / お問い合わせページ
- AdSense配置スペース

## 公開前に変更する項目
1. example.com を実際のドメインへ変更

3. AdSense承認後に実際の広告コードを設定

## 公開方法
フォルダ内のファイルをWebルートへそのままアップロードしてください。
